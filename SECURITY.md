# Sécurité

Merci de ne pas publier publiquement une vulnérabilité, un jeton, un identifiant de compte ou un extrait de journal contenant des informations personnelles.

Pour signaler un problème de sécurité, utilisez la fonctionnalité **Private vulnerability reporting** du dépôt GitHub lorsqu’elle est disponible.

Seuls les installeurs attachés aux Releases officielles de `BeeMulti/BEE-MULTI` doivent être considérés comme authentiques.
